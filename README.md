# Portofolio Pribadi

## Akses Online

Live Website: [https://dev-vislian.github.io/myport/](https://dev-vislian.github.io/myport/)

## Cara Menjalankan

```bash
npm install
npm run dev
```

Server dev berjalan di `http://localhost:5173`. Untuk produksi:

```bash
npm run build
npm run preview
```

## Catatan

- Portofolio khusus pribadi. Semua teks dan konten dikonfigurasi melalui `src/data.js`.
